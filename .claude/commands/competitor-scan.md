# Competitor Scan

경쟁사 변화를 추적하고 wiki를 업데이트한다.

## Steps
1. wiki/market/competitors.md 읽기
2. 각 경쟁사의 GitHub/웹사이트에서 최근 변화 확인:
   - 새 기능 출시
   - 가격 변경
   - 스타/포크 변화
   - 새 경쟁자 등장
3. 변화가 있으면 wiki/market/competitors.md 업데이트
4. VibeSafe에 미치는 영향 1줄 평가

## Output
| 경쟁사 | 변화 | VibeSafe 영향 | 대응 필요? |
|--------|------|--------------|-----------|

## Rules
- "위협 없음"이라고 쓰지 않는다. 항상 "왜 위협이 아닌지" 근거를 쓴다
- 새 경쟁자를 발견하면 즉시 추가한다
