# Wiki Decision

주요 결정을 기록하는 워크플로우.

## Steps

1. 결정 내용을 받는다
2. `wiki/decisions/log.md`에 추가한다:
   ```
   ### YYYY-MM-DD: (결정 제목)
   **결정:** (한 줄)
   **이유:** (왜 이렇게 결정했는가)
   **대안:** (고려했지만 선택하지 않은 것)
   **되돌릴 수 있나:** 예/아니오
   **관련 페이지:** [[wiki/...]]
   ```
3. 관련 위키 페이지를 업데이트한다
4. index.md를 갱신한다

## Rules
- "고려했지만 안 한 것"은 decisions/rejected.md에도 추가
- 되돌릴 수 없는 결정은 반드시 이유를 상세히 기록
