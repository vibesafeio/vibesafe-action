# Weekly Retrospective

주간 회고. wiki를 기반으로 한 주를 정리한다.

## Steps

1. `wiki/marketing/results.md`에서 KPI 변화 확인
2. `wiki/engineering/failure-log.md`에서 이번 주 버그 확인
3. `wiki/decisions/log.md`에서 이번 주 결정 확인
4. git log --oneline --since="7 days ago"로 커밋 확인

## Output
```
━━━ Week of YYYY-MM-DD ━━━
KPIs: Stars X->Y, Installs X->Y, Views X->Y
Shipped: (주요 변경 3개)
Bugs: (발견/수정 N건)
Decisions: (주요 결정 N건)
Lesson: (이번 주에 배운 가장 중요한 것 1줄)
Next week: (가장 중요한 행동 1개)
━━━━━━━━━━━━━━━━━━━━━━━
```

wiki/marketing/results.md 와 wiki/product/roadmap.md 를 업데이트한다.
