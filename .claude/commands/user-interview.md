# User Interview — Prep & Synthesis

사용자 인터뷰 전 질문 준비, 후 분석. 첫 외부 사용자 확보 후 실행.

## Prep Mode (인터뷰 전)
wiki/market/segments.md와 wiki/market/pmf-moment.md를 읽고:
1. 이 사용자가 어떤 세그먼트인지 파악
2. 검증해야 할 가정 3개 도출
3. 각 가정을 검증하는 질문 작성 (유도 질문 금지)

질문 원칙:
- "VibeSafe 어때요?" ❌ → "마지막으로 보안 스캔을 돌려본 게 언제예요?" ✅
- "이 기능 필요해요?" ❌ → "PR 올릴 때 가장 걱정되는 게 뭐예요?" ✅
- 과거 행동을 물어본다. 미래 의향을 묻지 않는다.

## Synthesis Mode (인터뷰 후)
raw/feedback/에 인터뷰 노트를 넣고 실행:
1. 핵심 인사이트 3개 추출
2. 기존 가정과 일치/충돌 여부 표시
3. wiki/market/segments.md 또는 wiki/market/validation.md 업데이트
4. "이 인터뷰로 바뀌어야 할 것" 1줄 제안
