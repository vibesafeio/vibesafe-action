# Wiki Status

현재 프로젝트 상태를 한눈에 보여주는 대시보드.

## Steps

1. `wiki/index.md` 읽기
2. `wiki/marketing/results.md` 읽기 (KPI)
3. `wiki/product/roadmap.md` 읽기 (다음 할 것)
4. `wiki/engineering/failure-log.md`에서 최근 3건 읽기

## Output Format
```
━━━ VibeSafe Status ━━━
Phase: (현재 단계)
KPI: Stars X / Installs X / Re-run X%
Next: (가장 중요한 다음 행동 1개)
Blockers: (있으면)
Recent bugs: (최근 3건 1줄씩)
Wiki health: (페이지 수, 고아, 오래된 것)
━━━━━━━━━━━━━━━━━━━━━
```
