# Experiment Design

가설을 검증하기 위한 최소 실험을 설계한다.

## Steps
1. 가설을 받는다: "X를 하면 Y가 될 것이다"
2. 가설을 검증 가능한 형태로 재구성:
   - 측정 가능한 Y (숫자)
   - 기간
   - 성공/실패 기준
3. 최소 실험 설계:
   - 뭘 만드는가 (최소한으로)
   - 누구에게 보여주는가
   - 뭘 측정하는가
   - 언제 판단하는가

## Output Format
```
가설: [한 줄]
성공 기준: [숫자 + 기간]
실험: [뭘 하는가]
측정: [뭘 보는가]
판단 시점: [언제]
실패 시: [뭘 하는가]
```

## Rules
- "더 많은 데이터가 필요하다"는 답이 아니다
- 2주 이상 걸리는 실험은 쪼개라
- 실험 결과는 wiki/decisions/log.md에 기록
