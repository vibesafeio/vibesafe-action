# Message Testing

타겟 세그먼트에 어떤 메시지가 먹히는지 테스트한다.

## Steps
1. wiki/market/segments.md에서 타겟 세그먼트 확인
2. wiki/marketing/messages.md에서 기존 메시지 전략 확인
3. 새 메시지 후보를 3개 생성:
   - 각각 다른 감정을 자극 (공포, 책임, 편의)
   - 각각 다른 형식 (질문, 사실, 스토리)
4. 각 메시지의 예상 반응을 시뮬레이션
5. A/B 테스트 방법 제안

## Output
| # | 메시지 | 감정 | 형식 | 예상 반응 | 테스트 방법 |
|---|--------|------|------|----------|-----------|

## Rules
- "AI가 위험하다"만 반복하지 않는다
- wiki/market/pmf-moment.md의 "사용자 데이터를 다루기 시작한 순간"을 반영
- 결과는 wiki/marketing/messages.md에 업데이트
