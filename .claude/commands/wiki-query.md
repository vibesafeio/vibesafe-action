# Wiki Query

위키를 검색하여 질문에 답하는 워크플로우.

## Steps

1. `wiki/index.md`를 읽는다
2. 질문과 관련된 페이지를 찾는다 (보통 1-3개)
3. 해당 페이지만 읽는다 (전체를 읽지 않는다)
4. 위키에 충분한 정보가 없으면 `raw/`에서 찾는다
5. 답변을 제공하고, 근거가 된 위키 페이지를 명시한다

## Rules
- raw/ 전체를 읽지 않는다. 위키 먼저, raw는 보충.
- 위키에 없는 정보는 "위키에 아직 없는 정보입니다"라고 말한다.
- 답변 후 "이 정보를 위키에 추가할까요?"라고 묻는다.
