## TLDR
두 메시지: "AI 코드가 위험하다" (유입) + "사용자 생기면 네 책임이다" (전환).
광고처럼 보이면 안 됨. 실험 데이터 공유가 핵심.

## Content

### 메시지 프레임워크
| 단계 | 메시지 | 감정 |
|------|--------|------|
| 유입 | "AI가 만든 코드, 보안 점수 0점" | 호기심 + 불안 |
| 관심 | "10개 프로젝트 스캔 결과 평균 23점" | 데이터 신뢰 |
| 전환 | "30초면 확인 가능. 무료." | 행동 장벽 제거 |
| 유지 | "매 PR마다 자동 체크" | 습관화 |

### 작동한 메시지 (OKKY 772뷰)
- 제목: AI가 만든 앱의 보안 취약점을 발견하는 방법
- 포인트: 개인 경험 ("내가 만든 앱이 0점") + 도구는 부차적
- 댓글 반응: "크로스 체크 필수" = VibeSafe 가치 공감

### 작동하지 않은 메시지 (dev.to 0 반응)
- 제목: "My Cursor-generated app had security issues. It scored 0 out of 100"
- 문제: 영어권 경쟁 콘텐츠 과다 + 타이밍/태그 미최적화

### 안티패턴
- ❌ "최고의 보안 도구" → 광고
- ❌ 기능 나열 → 지루함
- ❌ "반드시 써야 합니다" → 거부감
- ✅ "실험해봤더니 이런 결과가 나왔다" → 공유 가치
